# Practice 09 — Game Development with Pygame (Part 1)

## Overview
This practice contains three simple Python games/applications created using Pygame. The purpose is to learn graphics, keyboard input, animation, sound, and basic game loops.

## Projects

### 1. Moving Ball
- A red ball on a white background.
- The ball is controlled using arrow keys.
- Each key press moves the ball by 20 pixels.
- The ball cannot move outside the window.

### 2. Mickey's Clock
- Displays current minutes and seconds.
- Uses rotating hands.
- Synchronizes with the computer's system time.

### 3. Music Player
- Keyboard-controlled music player.
- Supports Play, Stop, Next, Previous, and Quit commands.
- Displays the playlist and current track.

## Technologies
- Python
- Pygame

## Installation
Install the required library:

```bash
python3 -m pip install -r requirements.txt
```

## Running the projects
Open the corresponding project folder in the terminal and run:

```bash
python3 main.py
```

## Keyboard Controls

### Moving Ball
- Up Arrow — Move up
- Down Arrow — Move down
- Left Arrow — Move left
- Right Arrow — Move right

### Music Player
- P — Play
- S — Stop
- N — Next
- B — Previous
- Q — Quit
